# AIMLCZG557 Exam Preparation

Reusable mid-sem preparation workspace for Artificial and Computational Intelligence.

This repo is organized to support cross-chat continuity, topic-by-topic tutoring, formula-sheet building, practice, mock exams, and safe local handling of instructor-provided files.

## Start Here

- Read `PROJECT_CONTEXT.md`
- Read `STUDY_PROGRESS.md`
- Read `WORKSPACE_INVENTORY.md`
- Use `AIMLCZG557_EXAM_PREPARATION_PLAN.md`
- Open `AIMLCZG557_VISUAL_LAB.html` for interactive revision
- Use the repo-local skill at `.agents/skills/aimlczg557-exam-tutor/`

## Layout

- `WORKSPACE_INVENTORY.md`: persisted classification of local source material and tracked prep artifacts
- `AIMLCZG557_EXAM_PREPARATION_PLAN.md`: 2-day plan built from local course material
- `PROJECT_CONTEXT.md`: stable shared context for future chats
- `STUDY_PROGRESS.md`: progress tracker and update rules
- `notes/`: formula sheet and future topic notes
- `practice/`: quizzes, numericals, mocks, and error log
- `sample-papers/`: local source-paper area plus tracked analyses
- `.agents/skills/aimlczg557-exam-tutor/`: repo-local tutoring skill

## Folder Zones

- Tracked prep workspace: root markdown files, `notes/`, `practice/`, `sample-papers/analysis/`, visual lab, and repo-local tutoring skill
- Local-only course material: `Files (Common Resources)-20260613/`, `OneDrive_3_13-06-2026/`, `OneDrive_4_13-06-2026/`, and source sample papers
- Mixed area: `sample-papers/` keeps original papers local in `source/` while preserving derived analysis in `analysis/`

## Safety

Instructor-provided recordings, slides, notebooks, source sample papers, and copyrighted reference material are intentionally kept local and excluded from Git tracking.
