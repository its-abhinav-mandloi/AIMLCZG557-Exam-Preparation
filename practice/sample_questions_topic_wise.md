## Emergency Route Planning Using Greedy Best First Search
Source: `Assign1_PS7.pdf`

1. Represent the city map as a graph.
2. Implement Greedy Best First Search in Python.
3. Use heuristic values to guide the search.
4. Print the visited nodes, optimal path, and total cost.
5. Compute the time complexity and space complexity from your implementation.
6. Explain the PEAS (Performance Measure, Environment, Actuators, Sensors) for the routing agent.
7. Explain the environmental characteristics for the given problem.
8. Explain the heuristic function used for the problem.

## A* Search And Heuristic Evaluation
Source: `Sample-questions-from-previous-year-exam.pptx`

1. A Rescue Agent is deployed in a flood-affected city to deliver medicines from the base camp at `(X1, Y1)` to a relief shelter at `(X5, Y4)` on a `5 x 5` grid with allowed moves `Up`, `Down`, `Left`, and `Right`, where blocked and waterlogged cells cannot be entered.
2. Expand and depict the search tree for exactly 3 levels for the above problem.
3. Calculate the path cost and heuristic values for all nodes at Levels 1 to 3.
4. Apply A* search and show all steps.
