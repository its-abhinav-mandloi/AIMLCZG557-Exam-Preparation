# Previous-Year Sample Questions Analysis

## Source Used

- `Files (Common Resources)-20260613/Webinar 2 materials/Sample-questions-from-previous-year-exam.pptx`

## Confirmed Question Styles Seen Locally

1. Grid-based A* problem
2. Exact search-tree expansion to a fixed depth
3. Calculation of `g(n)`, `h(n)`, and `f(n)`
4. Final-path cost computation
5. PEAS description for a real-world intelligent system
6. Task-environment classification with justification

## Implications For Preparation

- Search numericals are high priority.
- Clean step presentation matters, not just the final answer.
- PEAS and environment-classification questions are very plausible.
- The exam may mix formal AI vocabulary with practical scenario descriptions.

## Recommended Response Pattern

### For A*

- Write the legend and allowed moves
- State the heuristic definition
- Expand the tree level by level
- Tabulate `g`, `h`, and `f`
- Show the open-list choice at each step
- Write the final path and total cost

### For PEAS / environment questions

- Use exact headings
- Give one concise justification per environment dimension
