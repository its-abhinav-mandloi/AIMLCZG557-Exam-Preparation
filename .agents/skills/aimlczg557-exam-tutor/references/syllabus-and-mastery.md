## Mastery Rules

Never set `Mastered` unless one of these is true:

- the learner solved a closed-book numerical accurately
- the learner gave a correct closed-book explanation with notation
- the learner cleared a short quiz with strong reasoning

Use these status transitions:

- `Not started` -> `Learning`: after first explanation
- `Learning` -> `Practiced`: after one guided or lightly assisted attempt
- `Practiced` -> `Mastered`: after closed-book success
- any prior state -> `Needs review`: if recall fails or repeated mistakes appear

## Scope Guardrails

- If a new sample paper changes emphasis, update priority, not the confirmed syllabus boundary.
- If a topic is only in the full handout but outside `CS1-CS8`, exclude it from the mid-sem teaching path unless the user explicitly asks for broader coverage.
- If a local `CS8` slide deck is still unavailable, treat subtopic detail for `CS8` as inference from the handout and say so.
