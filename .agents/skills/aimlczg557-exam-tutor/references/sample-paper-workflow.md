# Sample Paper Workflow

Use this workflow for sample papers, assignments, previous-year questions, or user-attached mock tests.

1. Identify whether the artifact is authoritative, supportive, or inferred.
2. Extract question types:
   - definition
   - derivation
   - numerical
   - PEAS / environment
   - algorithm trace
   - model-answer theory
3. Map each question to syllabus topics.
4. Note which topics are repeatedly emphasized.
5. Distinguish:
   - confirmed exam style from direct evidence
   - likely exam style from repeated patterns
6. Create or update a tracked analysis file in `sample-papers/analysis/` if the artifact is worth preserving.
7. Only change study priority if the artifact materially shifts emphasis.
8. Update `STUDY_PROGRESS.md` only if the learner has actually attempted or completed work based on the paper.

## Numerical Analysis Checklist

- what is given
- what must be found
- required formulas
- intermediate tables
- common traps
- final answer format

## Model-Answer Checklist

- 2 to 5 mark answer: definition plus one example
- 6 to 10 mark answer: intuition, steps, formula, worked logic, limitation
